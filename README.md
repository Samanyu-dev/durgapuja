## ✨ What is Durga Idol Maker?

A **comprehensive mobile platform** built specifically for the artisans of **Kumartuli, Kolkata** — the historic birthplace of Durga Puja idols. This app combines **AI-powered design tools**, **voice-driven finance tracking**, and **end-to-end order management** into a single, offline-first solution.

> *"From clay to deity, from ledger to ledger — every artisan deserves modern tools."*

## ⚡ Quick Start

### Prerequisites
- Flutter SDK `^3.9.2`
- Android Studio / Xcode
- Firebase project configured
- `.env` file with API keys

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Samanyu-dev/durgapuja.git
cd durgapuja

# 2. Install dependencies
flutter pub get

# 3. Configure environment
cp .env.example .env
# Edit .env with your API keys

# 4. Generate app icons (after adding assets/icons/app_icon.png)
flutter pub run flutter_launcher_icons:main

# 5. Run the app
flutter run
```

## 📦 Build Release APK

```bash
# Step 1: Set up signing
# Copy the example and fill in your keystore details:
cp android/key.properties.example android/key.properties
# Edit android/key.properties with your production keystore info

# Step 2: Build release APK
flutter build apk --release

# Output:
# build/app/outputs/flutter-apk/app-release.apk
```

<details>
<summary><b>🔐 Keystore Setup (First Time)</b></summary>

```bash
# Generate upload keystore
keytool -genkey -v -keystore ~/upload-keystore.jks -keyalg RSA \
  -keysize 2048 -validity 10000 -alias upload

# Then update android/key.properties:
# storePassword=your_password
# keyPassword=your_password
# keyAlias=upload
# storeFile=/Users/you/upload-keystore.jks
```

</details>

## 🔑 Environment Variables

Create `.env` in the project root:

```env
# Firebase
FIREBASE_API_KEY=your_key
FIREBASE_PROJECT_ID=your_project

# AI Services
OPENAI_API_KEY=sk-your_key
KREA_API_KEY=your_key
REPLICATE_API_KEY=your_key
```

> ⚠️ `.env` is in `.gitignore`. Never commit secrets.
